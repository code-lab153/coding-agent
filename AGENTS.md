# Repository Rules

- Do not use agent frameworks or agent SDKs.
- Keep the architecture small and understandable.
- Do not include personal identity or university information.
- Do not include credentials, secrets, private keys, tokens, passwords, or real `.env` files.
- Preserve the complete Git commit history.
- Never force push.
- Never rewrite published history, including by rebase, squash, amend, or reset.
- Do not commit or push unless explicitly instructed by the user.
